粘贴单词表（助教输入 · 自建词库）

每行一个单词，格式：单词 + 词性 + 中文释义，多个词性释义依次排列。
词性支持英文缩写（v. / n. / adj. / adv. / vt. / vi. / prep. …）或中文（动词 / 名词 / 形容词…），
也支持复合词性（v&n / v.&n. / 动词&名词）。一个词性下的多个释义用逗号或顿号分隔，会拆成独立释义随机抽取。
分隔方式：Tab（直接从 Excel 复制即可）、空格、或分号。

示例：
mark　v&n. 标志、标记　n. 目标（测试时随机显示「v&n 标志」「v&n 标记」「n 目标」之一）
abandon　v. 抛弃，放弃　n. 放纵
well-known　adj. 著名的，众所周知的

使用说明与测试规则
选词方式：词库在 「① 词库」页 选定——内置词库挑好书、填好起止序号后点「载入词库」； 或用自己粘贴导入的自建词库点「使用」。载入后回到本页填写学生姓名、点「开始测试」才开考；本页只显示当前测试词库，可设置抽词数与答题规则。
抽取规则：每次开始测试都会重新随机打乱单词顺序（勾选「全部」时同样打乱后测试，不会按词库原顺序出题）。
释义提示：内置词汇书答题时会同时显示 基础释义 与 拔高释义（拔高释义只在部分词条存在）， 两档释义都只作提示，不参与批改。
测试规则（与助教人工流程一致）：每词随机展示 一个词性 + 中文释义（或选择全部显示），并给出 不超过单词字母数一半 的字母提示；学生在提示的空格上直接补全单词，如为随机显示模式还需写出 其余的词性和对应中文释义。每答完一题立即显示对错与正确答案，全程不可返回上一题。全部完成后自动批改、记录错词。
扩展词规则：名词 → 动词/形容词/副词/复数；动词 → 名词/形容词/副词/过去式/过去分词/现在分词/三单； 形容词 → 名词/动词/副词；副词 → 名词/动词/形容词；其他词性无扩展。扩展词的正确拼写由系统自动判定： 变形形式（过去式/分词/复数等）按规则 + 常用不规则表生成；词性转换形式从在线词典自动匹配校验 （联网查询该派生词是否真实存在且为目标词性，需联网；网络异常时自动回退为规则结果，不影响测试）。
